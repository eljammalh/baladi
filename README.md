# بلدي · Baladi

An Arabic-first marketplace for Jordan where local farmers, growers and home producers
list home-grown and home-made food, and buyers find healthy, local, affordable options nearby.

- Native Android: Kotlin, Jetpack Compose, Material 3, Hilt
- Every push to `main` builds a signed APK in GitHub Actions (see the **Actions** tab → latest run → **Artifacts**)
- Pushing a tag like `v0.1.0` also publishes a GitHub Release with the APK attached
